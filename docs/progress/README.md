# Progress Notes

Use dated notes to keep reviews easy to follow.

Suggested naming:

- `2026-05-11-project-setup.md`
- `2026-05-22-deliverable-1.md`
- `2026-05-18-group-fwd-mask.md`
- `2026-06-01-mdb-core.md`

Each note should stay short and answer:

- what changed,
- what was validated,
- what remains blocked or risky.
