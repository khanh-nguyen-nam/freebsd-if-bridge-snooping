# Patches

- `0001-if-bridge-group-fwd-mask.patch`: Deliverable 1 patch for FreeBSD `if_bridge(4)`.
- `0002-if-bridge-mdb-foundation.patch`: Incremental MDB structures, cleanup callout scaffolding, and VNET topology test patch. Apply after `0001`.
- `0003-if-bridge-ipv4-igmp-learning.patch`: Incremental IPv4 IGMP listener learning and unknown multicast flood fallback test. Apply after `0002`.
- `0004-if-bridge-mdb-forward.patch`: Incremental MDB-aware IPv4 multicast forwarding; prunes learned groups to listener ports only, falls back to flood for unknown groups, adds `mdb_selective_forward` ATF test. Apply after `0003`.
- `0005-if-bridge-snooping-counters.patch`: Incremental per-VNET observability counters (`mdb_entries`, `mdb_prune_hits`, `mdb_flood_fallback`, `mdb_parse_reject`, `mdb_expired`) exposed read-only via `ifconfig`/`libifconfig`, writable-to-zero for reset, adds `mdb_counters` ATF test. Apply after `0004`.
- `0006-if-bridge-router-port-learning.patch`: Incremental multicast-router-port learning; learns router ports from IGMP membership queries (keyed by VLAN, aged) and forwards learned groups to listeners plus router ports on the same VLAN, adds the `mdb_routers` counter and `mdb_router_forward` ATF test. Apply after `0005`.
- `0007-if-bridge-igmpv3-asm-refinement.patch`: Incremental conservative IGMPv3 ASM reduction; INCLUDE-family and non-empty EXCLUDE group records now create/refresh `(*,G)` listener state (revocation-only records still drive no state change), documents the reduction in `bridge.4`, adds the `mdb_igmpv3_source_join` ATF test. Apply after `0006`.
- `0008-if-bridge-link-local-exempt.patch`: Incremental fix excluding the link-local `224.0.0.0/24` block from IGMP snooping entirely (RFC 4541 2.1.1); adds a learn-side predicate and an independent forward-side guard so groups like mDNS's `224.0.0.251` are never learned or pruned, documents the exemption in `bridge.4`, adds the `mdb_link_local_exempt` ATF test. Found via `scripts/snooping-edge-cases.sh`, not by inspection. Apply after `0007`.
